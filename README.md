Під час аудиту безпеки клієнтського застосунку «Афіша подій міста» було змодельовано та усунуто XSS-вразливість,
пов'язану з виведенням поля локації події через innerHTML. Вразливе місце було переписано на безпечний вивід через textContent. 
Аналіз клієнтської пам'яті в localStorage та IndexedDB (зокрема сховища savedEvents) підтвердив відсутність чутливої чи 
персональної інформації. Перевірка вихідного коду засвідчила повну відсутність захардкоджених секретів. Для фінальної здачі 
та захисту трафіку застосунок успішно розгорнуто на платформі GitHub Pages, яка забезпечує підтримку протоколу HTTPS за замовчуванням
