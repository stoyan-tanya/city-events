Під час аудиту безпеки клієнтського застосунку «Афіша подій міста» XSS-вразливостей не виявлено,
оскільки проєкт реалізовано на React, який за замовчуванням безпечно екранує всі введені дані під час рендеру,
діючи як безпечний textContent. Аналіз клієнтської пам'яті в localStorage та
IndexedDB (зокрема сховища savedEvents) підтвердив відсутність чутливої чи персональної інформації,
оскільки там зберігаються лише загальнодоступні відомості про культурні події.
Перевірка вихідного коду засвідчила повну відсутність захардкоджених секретів,
паролів чи приватних API-ключів. Для фінальної здачі та захисту трафіку застосунок успішно розгорнуто на платформі GitHub Pages,
яка забезпечує підтримку протоколу HTTPS за замовчуванням.
